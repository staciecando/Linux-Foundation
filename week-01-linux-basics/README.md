## Commands Practiced

### pwd 
: shows the current working directory.

### ls
: lists files and directories.

### cd
: changes the current directory.

### mkdir
: creates a directory.

### touch
: creates an empty file.

The Linux kernel manages communication between applications and hardware, as well as system resources such as processes, memory, filesystems, and networking.


Linux technically = the Linux kernel
In everyday usage, people often say “Linux” to mean a Linux-based operating system
Ubuntu = a Linux distribution
A Linux distribution = Linux kernel + system tools + libraries + applications + package management, etc.

A desktop environment in Linux is a graphical user interface (GUI) that runs on top of the operating system.
The command line in Linux is an interface where users type commands for the operating system to execute.
A full Linux distribution includes software tools for performing file-related operations, system administration, user management, and software package management.
CentOS Stream, AlmaLinux, and Rocky Linux are free Linux distributions that are binary-compatible with Red Hat Enterprise Linux (RHEL).
