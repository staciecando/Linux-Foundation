 # Week 1 - Linux Basics

## Topics Learned
- Linux filesystem
- Terminal basics
- Absolute and relative paths
- Creating files and directories

## Commands Practiced

### pwd 
: shows the current working directory.

### ls
: lists files and directories.

### cd
: changes the current directory.

### mkdir
: creates a directory.

### touch
: creates an empty file.

## Practice

I created directories and files using the Linux terminal.

Example:

mkdir linux-practice
cd linux-practice
touch test.txt
ls -l
